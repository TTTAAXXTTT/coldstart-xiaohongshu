# v0.5.1：从使用者视角整理工作流

> **作者联系方式：QQ 230154231**  
> 软件交流、问题反馈与功能建议可联系作者。

主界面统一为“工作台、需求与评论、内容与排期、检查与历史、业务设置”。运行模式只有一个入口；暂停/继续只管理实际任务执行，业务设置不再同时重复展示多个总开关。

- 运行状态、当前步骤、排队顺序、等待原因和下一步计划由后台事实生成。
- 公开互动统一负责搜索和评论检查；内容规划使用已有来源，不重复搜索。
- 只评论模式关闭自动创作和发帖；旧版自定义配置保留，应用新模式后统一管理。
- 定时任务以完成时间和每段讨论的检查时间安排；失败单项退避，其他工作继续。
- 已暂停不再继续倒计时；收尾、后台未启动、网络中断独立显示。
- 等待队列与历史分开；取消只操作尚未开始的任务，清空时同时暂停以防立即补回。
- 发送未知结果仍隔离对应作品，独立回查和防止重发的约束保留。
