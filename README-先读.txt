完整解压到新目录，双击00_一键安装并启动.bat。
填写自己的内容方向、搜索词、模型地址/型号/Key，运行02扫码登录，再运行03打开工作台。
检查接入后，在首页选择“开启全自动评论与发帖”或“只开启公开评论与回复”。也可运行04_开启全自动公开互动.bat。
正常工作会自动搜索、读原文、发表评论、回查并监听新的公开回复，按上下文续答；可同时自动写稿、制作卡片并发表。
