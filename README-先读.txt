工作台只看四件事：是否在运行、当前具体步骤、下次何时执行、哪些项目需要处理。
评论文字在“需求与评论”，文章在“内容与排期”。等待任务和已完成历史已经分开。
暂停后当前请求先收尾，再停止新任务；排队不代表正在执行。
重复任务会合并；只评论模式不自动写稿发帖；搜索与创作不再重复搜索。

所需依赖自动检查安装，缺少时需要联网。本包不是完全离线包。
支持火山、DeepSeek、百炼、OpenAI及Chat Completions兼容接口，使用自己的地址、模型与Key。
只围绕公开问题交流，不报价、不谈交易，不读取或处理私信。
