提供内容生成、文字卡片、图文排期、公开帖子检索、公开评论与上下文续答，以及发送结果回查。只支持小红书；私信由使用者本人处理。

## 快速开始

1. 完整解压或克隆仓库到固定目录，双击 `00_一键安装并启动.bat`。
2. 在“我的业务与模型”填写自己的业务方向、关键词、模型地址、可调用模型名和 API Key。
3. 运行 `02_登录平台账号.bat`，由账号本人完成登录及平台要求的身份验证。
4. 在工作台检查连接，再选择只分析、公开评论，或评论与发帖模式。

本仓库已提供固定版本的小红书组件；首次缺少 Python、Pillow 或 Chromium 时，启动器会联网检查并自动准备。业务运行不需要 Node.js；完整前端自测需要 Node.js。

完整操作见 [使用说明](完整流程与使用说明.md)，也可双击根目录 HTML 版本。源码 ZIP 保留全部组件和安装入口。

## 主要功能

- 根据真实资料生成文章和本地文字卡片，可查看、编辑和安排排期。
- 搜索并读取公开文字内容，按业务方向判断是否适合参与。
- 拟稿、上下文读稿、公开评论与回复，核对发送账号、文字及目标关系。
- 单条评论发送结果不明时，仅隔离对应作品，其他作品继续；未知动作不自动重发。
- 同一未知稿件及相同内容副本不重发，不同稿件按排期和额度执行。
- 可配置用量、间隔及备用模型；兼容 Chat Completions 类型接口。
- 本机服务使用自动生成的调用口令，只监听本机地址。

当前按返回的文字分析，不能把未读取的截图当作已识别。平台返回范围、接口变化、服务商限流和账号验证会影响功能；不承诺获客、流量或永久可用。
